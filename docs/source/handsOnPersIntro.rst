Running mapPat locally
----------------------

The complete collection of R scripts and configuration tables used to run mapPat is available through the dedicated `gitHub repository <https://github.com/F3rika/mapPat.git>`_ and can be downloaded to run the application locally. Note that the dataset visualised by default on mapPat is automatically dowloaded from the dedicated `Zenodo Repository <https://doi.org/10.5281/zenodo.14163899>`_ upon running the app for the first time. The same applies each time a new dataset is selected for the first time through the dedicated widget (see :doc:`widgGen`). All downloaded dataset are stored on the user device so beware of memory usage.
